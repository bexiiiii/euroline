# Поиск: выложенный этап, 21.10.2026

Статус: выбранные изменения развёрнуты 21.10.2026 на https://euroline.getlinkhr.online. Секреты и настройки 1С не менялись. Выкладывалась серверная исходная база с точечным наложением `search-release-files.txt`, не вся грязная локальная рабочая копия.

## Что изменено

- `/api/search` и `/api/v1/search` принимают необязательный `brand`.
- Без однозначного бренда возвращаются кандидаты и `selectionRequired: true`; запрос аналогов не выполняется.
- После выбора запрос кроссов выполняется только для выбранных артикула и бренда. Дедупликация учитывает оба поля; бренды с одинаковым номером не объединяются.
- Свои предложения связываются с локальным товаром по нормализованному SKU/коду и бренду. При неоднозначном соответствии цена и остатки не присваиваются. Передаются `productId`, `onecRefKey`, складской `refKey`.
- Новая страница: выбор детали → её предложения по складам → отдельные возможные замены. Сохранены белый/серый/оранжевый стиль и существующие компоненты. Применён frontend-ui-ux с приоритетом сохранения стиля Euroline.
- Сортировка по наличию/количеству, фильтр бренда замены, фото и действующая пагинация. Состояние фильтров в URL. Просроченный ответ поиска не заменяет более новый.
- Известный склад показывается и при нуле. Отсутствующие данные об остатке показаны как неизвестные, а не ноль.
- Новый `POST /api/cart/offers` принимает только `productId`, `warehouseRefKey`, `quantity`; цену и название склада определяет сервер. Проверяется суммарное количество выбранного предложения.
- Изменение/удаление корзины по ID строки, поэтому один товар на двух складах не смешивается. SKU отображается вместо внутреннего кода 1С при его наличии.
- Покупка нового предложения без подтверждённой положительной цены недоступна: предлагается уточнить цену. Старый сценарий заявок без склада сохранён.

## Что ещё нужно до полной приёмки

1. Подтверждённый источник грузовой применяемости и кроссов. UMAPI `type` не является признаком грузового автомобиля. Белый список производителей также недостаточен. Сейчас фильтр «только грузовики» НЕ реализован; кроссы честно помечены `UNVERIFIED`.
2. Обновление 21.10.2026: пара WABCO 4410329212 ↔ AUGER 71932 теперь находится автоматически через общий OE из UMAPI, без ручной привязки. Обе стороны проверены на production. Это кандидаты на замену, не гарантия применяемости. Нельзя автоматически делать все кроссы симметричными/транзитивными. Подробности и тесты — `AUTOMATIC-ANALOGS-RESEARCH-2026-10-21.md`.
3. Бренд части старых товаров 1С всё ещё определяется существующим правилом по первому слову названия. Нужны явные производители/проверенные привязки для неоднозначных записей.
4. Старые API добавления по OEM/ID сохранены для других экранов; их article-only сопоставление и клиентская цена требуют отдельного перевода на серверные предложения. Новый endpoint не устраняет риски старых endpoint.
5. Оформление через реальные сервисы и HTTP-контроллеры проверено на копии БД, но production-auth фильтры и внешняя доставка в 1С не входили в изолированный тест. Повторная проверка цены/остатка именно перед списанием не переписана. Старые сценарии заявок без цены остаются отдельной задачей.
6. Живой тестовый заказ НЕ создан: пользователь указал аккаунт, но пока не указал разрешённую сумму. Нельзя подменять реальную цену или пополнять баланс для такого теста без согласования.
